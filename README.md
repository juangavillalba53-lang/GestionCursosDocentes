# Gestion de Cursos y Docentes

TP integrador de Programacion III - Actividad 2.

Programa en Java con Swing para cargar docentes y cursos, asignar docentes a los cursos y ver reportes. Los datos se guardan en memoria.

Para ejecutarlo abrir el proyecto en IntelliJ y correr Main.java.

El informe y los diagramas estan en la carpeta docs.
