# Sistema de Gestión de Cursos y Docentes

Proyecto integrador de Programación III – IPESMI (Actividad 2).

Aplicación de escritorio en Java Swing para registrar y modificar docentes y cursos, asignar docentes a cursos controlando la carga horaria máxima, buscar docentes por especialidad y generar reportes. Los datos se guardan en memoria con colecciones.

## Ejecución

1. Abrir la carpeta del proyecto en IntelliJ IDEA.
2. Configurar como SDK del proyecto un JDK 21 o superior.
3. Ejecutar `src/Main.java`.
